# Skradin i NP Krka - Turistički vodič

Turistički vodič kroz Skradin i Nacionalni park Krka. 
Stranica prikazuje atrakcije, praktične informacije i kontakt formu.

## Live demo
https://sensational-gumption-4e2c52.netlify.app

## Stranice
- index.html - Naslovnica
- atrakcije.html - Atrakcije s filterom po kategoriji
- prakticne-info.html - Praktične informacije
- kontakt.html - Kontakt forma

## Tehnologije
HTML5, CSS3 (Flexbox, Grid, CSS varijable), JavaScript (vanilla)
Google Analytics 4, Netlify hosting
